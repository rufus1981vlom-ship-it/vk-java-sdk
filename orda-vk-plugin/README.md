# Orda VK (Paper 1.20.4)

## Что умеет
- Два чата VK: один для команд (`command-chat-id`), второй для игровых событий (`event-chat-id`).
- Русские/транслит-алиасы команд (`!admins` / `!админы`, `set` / `сет`, `!rnick` / `!рник`, `!ban` / `!бан` и т.д.).
- Привязка VK пользователя к Minecraft нику.
- Управление беседой VK: кик, бан по сроку в днях, разбан, автокик при повторном приглашении забаненного.
- `!cmd` отправляет в консоль команду любой длины (например `!cmd ban pommesshooter 1d`) и отвечает `Команда отправлена!`.
- Гибкий доступ через `config.yml`:
  - `vk.command-policy` — blacklist/whitelist для `!cmd`
  - `vk.bot-command-access` — минимальный уровень на каждую команду бота

## Команды
- `!help`, `!хелп`, `!помощь`
- `!admins`, `!админы`
  - Выводит админов в формате: `[https://vk.com/username|Имя Фамилия] - nick (lvl X)`
- `!admin set @screenname НИК [уровень]`
- `!admin set @id12345(...) НИК [уровень]`
- `!admin set id12345 НИК [уровень]`
- `!admin сет ...` — русская версия set
- `!admin level @user 1..4` (`!admin уровень ...`)
- `!admin remove @user` (`!admin удалить ...`)
  - Дополнительно отправляет в консоль: `lp user НИК parent set default`
- `!rnick @user НИК`, `!рник @user НИК`
- `!kick @user причина`, `!кик @user причина`
  - Удаляет из беседы
- `!ban @user причина [1d|53d]`, `!бан ...`
  - Банит в беседе + кикает сейчас; если срок не указан — бессрочно
  - При новом приглашении участник кикается автоматически, пока в бан-листе
- `!unban @user`, `!разбан @user`
- `!noname`, `!ноунэйм`
  - Проверяет участников беседы и выводит тех, у кого нет привязанного ника
- `!cmd <команда>`
  - Примеры: `!cmd say test`, `!cmd ban pommesshooter 1d`, `!cmd lp user nick parent set vip`

## Уровни админов
- 1..4
- Уровень 1 не может снимать/менять уровень 4
- Уровни 3 и 4 могут назначать уровень 1
- Назначение уровней выше 1 — только уровень 4

## Идея для улучшения
Добавить runtime-команды управления политиками (без редактирования файла), например:
`!policy mode whitelist`, `!policy blacklist add op`, `!policy access cmd 2`.
